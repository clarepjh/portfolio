# Clare Poh Jia Hui — Portfolio

Static, single-page portfolio built with HTML, CSS, and a small vanilla-JavaScript rabbit runner. No build step or package dependency is required.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

GitHub Pages address: https://clarepjh.github.io/portfolio/

Deploy from the `main` branch and repository root. Contact links are public as approved; no resume download is included.

The rabbit runner opens from the pixel rabbit. It starts only when opened and keeps the portfolio layout unchanged behind its dialog. Use Space, Up Arrow, or Jump to hop. After a run, enter a name to add the score to the temporary top-five board; closing the game clears the board. With reduced motion enabled, the runner opens paused; choose Play animation to opt in.
